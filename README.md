# Shatter

Shatter is a browser based gravity well rock shooter. Fly by inertia, break armored rocks through their fragments, and use a guided torpedo that recharges over ten seconds. The star bends ballistic shots and rocks while leaving the ship and torpedo under powered flight.

## Install and run

```sh
npm ci
npm run dev
```

Open the local Vite URL printed in the terminal. To produce the static production site in `dist/`:

```sh
npm run build
```

## Controls

- **Arrow keys / WASD:** turn and thrust
- **Space:** fire the gun
- **F:** launch the guided torpedo
- **Enter / Space:** confirm a menu choice
- **Up / Down:** move through menus
- **P / Escape:** pause or resume; Escape also leaves information screens
- **M:** mute or unmute sound
- **Backquote:** show or hide the engine debug overlay

On-screen touch controls are available on touch devices. The menus also support pointer and touch selection.
